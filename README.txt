HOW TO DEPLOY ON NETLIFY
1. Extract this ZIP on your phone/computer.
2. Upload the extracted website folder contents to Netlify's manual deploy page (or drag the extracted folder into the deploy area if supported).
3. Keep index.html, styles.css, script.js and the assets folder together.
4. Do not upload only index.html; the CSS, JS and assets are required.
